# DEJA — ديجا | موقع طلب أونلاين عبر واتساب

موقع ثابت (HTML + CSS + JavaScript فقط) جاهز للنشر على GitHub Pages. لا يوجد Backend ولا لوحة تحكم.

## أين أضيف أو أعدّل المنتجات؟
كل شيء في ملف واحد: **`js/data.js`**
- `SITE`: رقم واتساب، رسوم التوصيل، الحد الأدنى للطلب.
- `CATEGORIES`: الأقسام.
- `PRODUCTS`: المنتجات. في أعلى الملف تعليق عربي وقالب جاهز للنسخ.

### إضافة منتج
انسخ أي منتج داخل `PRODUCTS`، غيّر البيانات، واجعل `id` فريدًا و`category` مطابقًا لمفتاح قسم موجود.
- `available: false` يعرض "غير متاح" ويمنع الطلب.
- `featured: true` يظهر في المنتجات المميزة بالرئيسية.
- `sizes` للأحجام (ميديم/لارج، سنجل/دبل)، و`extras` للإضافات (`price` ثابت أو `priceBySize`).

### إضافة صورة
ضع الصورة في `assets/images/products/` واكتب مسارها في `image` للمنتج. إذا لم تكن الصورة موجودة تظهر بطاقة بديلة بهوية ديجا.

### إضافة قسم
أضف عنصرًا جديدًا في `CATEGORIES` (`key`, `name`, `order`, `enabled`)، ثم استخدم `key` في `category` للمنتجات.

## رسوم التوصيل
لم تُذكر في قائمة الطعام، فلم يتم افتراض رقم. `deliveryFee: null` يكتب "تُحدد حسب المنطقة" في الرسالة ولا يضيفها للإجمالي. ضع رقمًا (مثل `20`) ليُضاف تلقائيًا للتوصيل فقط.

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` / `js/home.js` | الرئيسية: البطل، المميزة، الأقسام، الوجبات، ليه ديجا |
| `menu.html` / `js/menu.js` | المنيو: بحث، تصفية بالأقسام، ترتيب بالسعر |
| `product.html` / `js/product.js` | تفاصيل المنتج: الحجم، الإضافات، الكمية، الملاحظات (وتعديل عنصر من السلة) |
| `cart.html` / `js/cart.js` | السلة، بيانات العميل، إرسال الطلب |
| `js/data.js` | **كل بيانات المنتجات والأقسام والإعدادات** |
| `js/storage.js` | حفظ السلة فقط في LocalStorage (أرقام واختيارات، بدون أسعار) |
| `js/app.js` | الهيدر والفوتر، حساب الأسعار، بطاقة المنتج، الأيقونات |
| `js/whatsapp.js` | بناء رسالة الطلب بالعربية ورابط `wa.me` |
| `css/style.css`, `responsive.css`, `animations.css` | التصميم، المتجاوب، الحركة (تحترم `prefers-reduced-motion`) |
| `assets/` | الشعار والشيف والزخارف المأخوذة من ملفات الهوية |

## التشغيل محليًا
افتح مجلد المشروع في الطرفية ثم `python3 -m http.server 8000` وافتح `http://localhost:8000`.
(يُفضل ذلك بدل فتح الملفات مباشرة.)

## النشر على GitHub Pages
1. ارفع محتويات المجلد في مستودع GitHub (يكون `index.html` في الجذر).
2. Settings ثم Pages ثم Source: Deploy from a branch ثم `main` / `root`.
3. المسارات كلها نسبية، فتعمل على رابط المستودع مباشرة.

## ملاحظات
- السلة تُحفظ في المتصفح فقط. المنتجات تأتي من `data.js` دائمًا.
- الطلب يُرسله العميل بنفسه من واتساب، والموقع لا يؤكد الطلب تلقائيًا.
- الخط (IBM Plex Sans Arabic) يُحمَّل من Google Fonts ويوجد بديل من خطوط النظام.
